## Deskripsi Project

Repository ini digunakan untuk menyimpan source code, aset, scene, dan dokumentasi Praktikum Augmented Reality yang dikembangkan menggunakan Unity 6.

Project mencakup pembuatan lingkungan 3D, pengaturan kamera dan audio, dasar pemrograman C#, interaksi objek, serta proses build aplikasi untuk perangkat Android.

## Tujuan Praktikum

1. Memahami penggunaan Unity sebagai lingkungan pengembangan aplikasi 3D dan AR.
2. Membuat dan mengatur objek 3D menggunakan material, pencahayaan, dan prefab.
3. Mengimplementasikan kamera dan audio.
4. Mempelajari pemrograman C# untuk mengatur perilaku objek.
5. Mengembangkan mini game interaktif menggunakan input, collision, dan trigger.
6. Melakukan pengujian dan build aplikasi Android.
7. Mendokumentasikan perkembangan praktikum menggunakan Git dan GitHub.

## Struktur Project

- `Assets/` — Scene, script C#, material, prefab, dan audio.
- `Packages/` — Konfigurasi package Unity.
- `ProjectSettings/` — Pengaturan project Unity.
- `Dokumentasi/` — Laporan dan bukti pengerjaan praktikum per pertemuan.
- `.gitignore` — Aturan pengecualian file yang tidak perlu diunggah.

## Hasil Pengembangan

Project telah digunakan untuk membuat diorama 3D dan mini game interaktif dengan objek player, obstacle, dan target.

Mini game juga telah berhasil dibuild menjadi APK dan dijalankan pada perangkat Android OPPO A57.

Pengujian dan penyempurnaan fitur, termasuk audio Android, dilakukan secara bertahap.

## Dokumentasi Praktikum

Dokumentasi setiap pertemuan akan disimpan di dalam folder `Dokumentasi/` dan diperbarui mengikuti perkembangan pengerjaan.
